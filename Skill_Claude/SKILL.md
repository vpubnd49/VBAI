# Skill: Claude Code (Anthropic)

Agent hỗ trợ lập trình thông minh từ Anthropic.

### Cách sử dụng
- **Extension:** Mở thanh Sidebar Antigravity, chọn icon Claude.
- **Terminal:** Chạy lệnh `claude-code` để bắt đầu phiên làm việc agentic.
- **Tính năng:** Tự động sửa lỗi, viết code, rà soát logic và chạy test.

### Yêu cầu
- Đã cài đặt Extension `anthropic.claude-code`.
- Đã cài đặt CLI `@anthropic-ai/claude-code`.
- Cần login bằng tài khoản Anthropic.
