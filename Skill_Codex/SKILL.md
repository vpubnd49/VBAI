# Skill: Codex (OpenAI)

Agent hỗ trợ lập trình và giải quyết bài toán kỹ thuật từ OpenAI.

### Cách sử dụng
- **Extension:** Mở thanh Sidebar Antigravity, chọn icon OpenAI/Codex.
- **Terminal:** Chạy lệnh `codex` để tương tác trực tiếp với model coding agentic.
- **Tính năng:** Sinh code từ ngôn ngữ tự nhiên, giải thích thuật toán, và tối ưu hóa hiệu suất.

### Yêu cầu
- Đã cài đặt Extension `openai.chatgpt`.
- Đã cài đặt CLI `@openai/codex`.
- Cần login bằng OpenAI API Key hoặc tài khoản ChatGPT Plus/Pro.
