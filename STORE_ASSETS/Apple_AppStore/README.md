# HƯỚNG DẪN TẢI TÀI NGUYÊN LÊN APPLE APP STORE CONNECT

Thư mục này chứa đầy đủ tất cả tài nguyên hình ảnh được thiết kế và xuất chuẩn 100% theo quy cách của Apple:

## 1. Biểu tượng ứng dụng (`01_App_Store_Icon_1024x1024`)
- **Vị trí tải**: `App Store Connect` > `General App Information` > `App Icon`.
- **Kích thước**: Đúng chuẩn `1024 × 1024 px`.
- **Lưu ý đặc biệt**: File xuất hệ màu `RGB 24-bit`, **hoàn toàn KHÔNG chứa kênh Alpha (No Transparency)** để tránh lỗi bị Apple từ chối.
- File: `vbai-appstore-icon-dark-1024x1024.png`.

## 2. Ảnh chụp màn hình iPhone 6.7" / 6.9" (`02_iPhone_Screenshots_1290x2796`)
- **Vị trí tải**: `App Store` > `iOS App` > `Screenshots` > tab `6.7" Display` (hoặc `6.9" Display`).
- **Kích thước**: Đúng chuẩn `1290 × 2796 px` (chuẩn iPhone 16 Pro Max, 15 Pro Max, 14 Pro Max).
- Kéo thả 4 file theo thứ tự:
  1. `01_tro_ly_phap_ly_ai_1290x2796.png`
  2. `02_tra_cuu_van_ban_thong_minh_1290x2796.png`
  3. `03_ra_soat_the_thuc_nd30_1290x2796.png`
  4. `04_kho_bieu_mau_chuan_1290x2796.png`

## 3. Ảnh chụp màn hình iPad 12.9" / 13" (`03_iPad_Screenshots_2048x2732`)
- **Vị trí tải**: Tab `12.9" Display` (nếu ứng dụng bật hỗ trợ iPad).
- **Kích thước**: Đúng chuẩn `2048 × 2732 px` (iPad Pro 12.9" / 13" M4).
- Kéo thả 4 file tương ứng từ 01 đến 04.
