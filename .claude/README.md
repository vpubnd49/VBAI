# Claude Project Config

Thu muc `.claude/` duoc dung de dong bo cau hinh Claude Code cho repo VBAI.

## Cac tep chinh

- `settings.json`: Cau hinh runtime/tool cho Claude Code.
- `prompts/legal-vbpl-system.md`: Prompt he thong VBPL dung chung.
- `worktrees/`: Thu muc Claude su dung cho cac phien lam viec worktree.

## Cach dung nhanh

1. Cai Claude Code CLI/extension.
2. Mo repo nay trong Claude Code.
3. Claude se nap cau hinh tu `.claude/settings.json` va prompt mau trong `prompts/`.
